# Rally Kong Videojuego

**Rally Kong** is a 2D platformer game developed in **C++ using Cocos2d-x**. The project is inspired by classic arcade platforming games and features character selection, multiple levels, enemies, collectibles, animations, and different gameplay mechanics.

## 📁 Project Contents

### 1. Classes

The **Classes** folder contains the `.cpp` and `.h` files that define the game's scenes, gameplay logic, and application configuration.

The main classes included in the project are:

- **HelloWorldScene:** Contains the main menu of the game and provides access to the different game options.
- **CharactersMenuScene:** Provides the character selection interface before starting the game.
- **NewGameScene:** Contains the first level of the game, including its environment, gameplay elements, enemies, and player interactions.
- **Level2:** Contains the second level, introducing a different environment and a higher level of difficulty.
- **Level3:** Contains the third level, continuing the progression with a more challenging environment and gameplay.
- **AppDelegate:** Handles the initial configuration of the application, including the game window and application lifecycle.

## 🎨 Resources

The **Resources** folder contains the graphical and game assets required to build the different scenes and gameplay elements.

### Characters and Animations

The project includes sprite resources used to create character animations for different actions and directions, including:

- Walking
- Running
- Jumping
- Crouching
- Left and right movement

These resources are used throughout the game to provide animated character movement and interaction.

### Enemies and Static Assets

The project includes graphical resources for enemies and other static elements used to construct the different levels.

These assets are integrated into the scenes to create the game's environments and gameplay challenges.

### Level Environments

Resources are provided for creating the different landscape layers used throughout the three levels. These elements allow each level to have its own visual environment and layout.

### Ground

The project includes resources used to construct the ground and platforms where the characters move and interact.

### Collectibles

The game includes collectible objects such as:

- **Coins**
- **Hearts**

These objects are placed throughout the levels and are part of the game's gameplay mechanics.

## 🎮 Game Features

### Character Selection

The game includes a character selection system that allows the player to choose between different playable characters. Each character has its own visual design and movement characteristics.

### Player Movement

The game implements several basic platforming mechanics, including:

- Walking
- Running
- Jumping
- Crouching
- Movement in both left and right directions

These mechanics allow the player to navigate the environments and interact with the different elements found throughout the levels.

### Levels

Rally Kong contains **three levels** with progressively increasing difficulty.

Each level features its own environment, layout, enemies, and gameplay challenges. The progression is designed to introduce the player to the game mechanics before increasing the complexity of the challenges.

### Enemies

Different types of enemies are incorporated into the levels. They act as obstacles that the player must avoid or interact with while progressing through each stage.

### Collectibles

Coins and hearts are placed throughout the levels as collectible gameplay elements. They provide additional interaction opportunities while the player progresses through the stages.

### Animations

Character sprites and animation resources are integrated throughout the game to represent different actions and movement states.

Animations are used for actions such as walking, running, jumping, and crouching, helping provide visual feedback during gameplay.

## ▶️ How to Run

Before running the project, make sure that the required Cocos2d-x environment and project resources are properly configured.

1. Download or clone the repository.
2. Download the required resources if they are provided separately.
3. Place the resources in their corresponding project directories.
4. Open the project using the appropriate Cocos2d-x development environment.
5. Build the project.
6. Run the generated application.

**Important:** Make sure all required resources are available in their corresponding folders before building the project.
