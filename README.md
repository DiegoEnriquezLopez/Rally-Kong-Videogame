# Rally Kong Videojuego

Rally Kong is a 2D platformer game developed in **C++ using Cocos2d-x**. The project is inspired by classic arcade platforming games and features character selection, multiple levels, enemies, collectibles, animations, and different gameplay mechanics.

## Project Contents

### Classes

The **Classes** folder contains the `.cpp` and `.h` files that define the game's scenes, gameplay logic, and application configuration.

The main classes included in the project are:

* **HelloWorldScene:** Contains the main menu of the game.
* **CharactersMenuScene:** Provides the character selection interface.
* **NewGameScene:** Handles the initial gameplay scene.
* **Level2:** Handles the second gameplay scene.
* **Level3:** Handles the third gameplay scene.
* **AppDelegate:** Handles the initial configuration of the application, including the game window and application lifecycle.

## Resources

The **Resources** folder contains the graphical and game assets required to build the different scenes and gameplay elements.

### Characters and Animations

The project includes sprite resources used to create character animations for different actions and directions, including:

- Walking
- Running
- Jumping
- Crouching
- Left and right movement

### Enemies and Static Assets

The project includes graphical resources for enemies and other static elements used to construct the environments.

### Level Environments

Resources are provided for creating the different landscape layers used throughout the game, allowing each stage to have its own environment and layout.

### Ground

The project includes resources used to construct the ground and platforms where the characters move and interact.

### Collectibles

The game includes collectible objects such as:

- Coins
- Hearts

## PruebaDiego

The **PruebaDiego** folder is generated by Cocos2d-x and contains the additional files and resources required to build and execute the project.

## Game Features

### Character Selection

The game includes a character selection system that allows the player to choose between different playable characters. Each character has its own visual design and movement characteristics.

### Player Movement

The game implements several platforming mechanics, including:

* Walking
* Running
* Jumping
* Crouching
* Movement in both left and right directions

### Enemies

Different types of enemies are incorporated into the gameplay. They act as obstacles that the player must avoid or interact with while progressing through the stages.

## Instructions to Modify the Project

To modify or recreate the project, follow these requirements and steps:

1. Ensure you have **CMake** and **Python 2.7.16** installed.
2. Install **Cocos2d-x**.
3. Create a new project from the command prompt.
4. Open the generated `.sln` file.
5. Download all the resources and classes mentioned above.
6. Add them to their corresponding directories in the project.
