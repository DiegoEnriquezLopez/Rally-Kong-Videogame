# Rally-Kong-Videojuego

Rally Kong - Game Project

Please read the instructions carefully to download the resources and files needed to run the game.


Contents of the Project

1. Classes
This folder contains all the .cpp and .h files needed to run the game. The classes included are as follows:

- HelloWorldScene: Contains the main menu of the game.

- CharactersMenuScene: The menu for selecting characters.

- NewGameScene: The first level of the game.

- Level2: The second level of the game.

- Level3: The third level of the game.

- AppDelegate: Adjusts the window size for the game.

2. Resources Folder

Resources for creating animations for all characters for actions such as jumping, running, crouching in left and right directions:

- Resources for enemies and static assets.

- Layers for the landscapes of the levels.

- Resource for creating the ground.

- Collectible objects like coins and hearts.

3. PruebaDiego Folder

This folder, generated by cocos2d-x, contains all the resources needed to execute the project.

4. Video Explanation

This video explains the game dynamics, the gameplay, and its objectives.

5. Instructions to Modify the Project

- Ensure you have CMake and Python version 2.7.16 installed.

- Install cocos2d-x.

- Create a new project from the command prompt.

- Open the generated .sln file.

Download all the mentioned resources and classes above and implement them into your project.

You can download the resources with the next link: https://drive.google.com/drive/folders/1lL1zvf3-6HMWdUrgHvdtzf_F_P4LA4xU?usp=drive_link
